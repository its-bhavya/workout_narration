# Archived v1 data

These synthetic videos, annotations, manifests, pose features, windows, models,
evaluation outputs and diagnostics belong to the contributor-grouped v1 split.
The `stuN` contributor prefixes were treated as subjects in that protocol.
They must not be mixed with v2 data, features, windows, models or results.

Paths below preserve their original repository-relative structure: `data/...`
and `outputs/...`. Files were moved, not deleted. The old `data/manifests/splits.csv`
remains in its original location for provenance. Upstream screening, raw footage,
source repetition boundaries and the pretrained MediaPipe model remain active.

The v1 `batch_checkpoint.json` was absent at archival time. Source-clip pose
pilot caches were preserved inside the archived `data/features/` tree as well.
No v1 artifacts are used to initialize v2 usage or rendering checkpoints.
